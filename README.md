# Diemcraft privacy pages

Privacy policies for Diemcraft apps, published with GitHub Pages at
https://dominicbrett.github.io/diemcraft-privacy-pages/

Each app has its own folder:

- `mellowgut/` — MellowGut ([privacy policy](https://dominicbrett.github.io/diemcraft-privacy-pages/mellowgut/privacy.html))

To add an app, create a folder with its `index.html` and `privacy.html` (link
`../style.css` for the shared look) and add it to the list in `index.html`.
